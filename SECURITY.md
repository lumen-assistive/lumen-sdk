# Security Policy

This repository defines shared contracts and ships no sensor access or
network code of its own; most security-relevant behavior lives in
`lumen-core`, which implements these contracts, and in `lumen-app`.

If you find a vulnerability that originates in this repository (for
example, a contract that makes it easy for an implementer to leak data
unintentionally), please report it the same way as for any other
repository in the organization: do not open a public issue, and instead
use GitHub's private vulnerability reporting on this repository
(repository page, "Security" tab, "Report a vulnerability").

See the [organization-wide security policy](https://github.com/lumen-assistive/.github/blob/main/SECURITY.md)
for response times and scope.
